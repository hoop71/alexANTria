## The Claim

Traditional AI agents load **all documentation** into context, causing attention degradation and context rot. Models perform worse when context exceeds soft limits—even within their stated window.

**alexANTria uses RLM architecture** to prevent this: agents load only what they need, when they need it. Context stays fresh, attention stays focused.

## How It Works: Three Pools

RLM architecture organizes context into three pools:

```
📁 PROGRAMMATIC POOL
   ├─ 50+ documentation files (317.7 KB total)
   └─ Available for retrieval, not loaded until needed

🔥 TOKENIZED POOL
   ├─ CLAUDE.md (5 KB - always loaded)
   └─ Task-relevant files (16.3 KB - loaded on demand)

💡 INTENTIONAL POOL
   ├─ Strategic decisions (ANT-STRATEGY.md)
   ├─ Product context (ANT-PRODUCT.md)
   └─ Read when agents need human wisdom
```

Only the **Tokenized Pool** (21.3 KB) stays in active attention. The rest waits in the **Programmatic Pool** until needed.

Result: **93.3% of documentation never enters the attention window.**

## The Science

Research shows context rot is **structural**—not a model limitation. When context exceeds soft limits (typically 50-70K tokens), quality degrades:

- Attention becomes diffuse
- Retrieval accuracy drops
- Response quality suffers

**RLM prevents this** by keeping active context under 10K tokens through selective loading. Agents work with fresh, focused context—every time.
